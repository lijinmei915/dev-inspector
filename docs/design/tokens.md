# Token 规范

## 原则

- 颜色、圆角、阴影、字号优先通过 token 管理
- 组件里不要直接散落硬编码视觉值
- 例外值只留在组件自己的语义槽位里
- 控件当前值命中 token 时，主面板触发器展示 token label；原始值放在下拉项或详情里，不在触发器外侧重复展示
- token 触发器宽度按内容 Hug 自适应，不用填满剩余空间
- 字段级 token 入口采用 hover / focus 出现的无边框四小块 icon；点击后打开 token 下拉
- token 下拉展示 token 名、当前数值和使用场景；没有可用 token 时保留空值项，并展示 `No variables available` 空状态，不把空值当 token
- 面板控件里 px 类 token 或自定义数值默认去掉 `px` 后缀展示，底层 CSS 值仍保留单位；文字字号触发器例外，保留 `px` 后缀以区分字重等裸数字
- 未命中 token 的值才按自定义裸值展示
- `自定义` 是来源状态，不是常驻参数按钮；预设下拉底部只能提供“基于当前样式自定义”动作，进入单项调整后主面板直接展示可编辑参数
- 紫色只用于 token 命中值和组件语义值；`自定义`、硬编码值、未命中 token 的值一律使用深色文字，不使用紫色强调
- 修改记录里的对象名使用最强文字 token（`--color-text-strong` / `#0f172a`），不使用紫色，避免误读为可点击链接或组件语义值
- `无`、`0`、`none` 这类空值状态不算 token，使用弱灰或深色文字，不使用紫色
- `transparent` / 透明色属于空色值，显示为 `无` 或 `透明`；色块必须使用棋盘格或斜线空态，不用纯白色块，避免误认为白色
- 阴影遵循 token / 自定义双态：命中 token 时只读展示 token、预览和摘要；进入自定义后才展示 X/Y/模糊/扩散/颜色等参数，并即时作用到页面
- 阴影为空时不展示 `无` 选择器，外层 section 标题右侧提供 `+` 添加入口。
- 带视觉预览的 token 入口统一使用同一选择控件：文字色、背景色、边框色、阴影色和阴影 token 都只在触发器内展示预览块与 token / 状态名，具体 hex / rgba / shadow 值放到下拉或 tooltip
- 颜色 token 下拉必须拆成上方色板滚动区和底部固定 footer row；底部自定义输入区始终贴在弹层底部，不随色板内容滚动；外层下拉不额外叠加底部 padding，footer 自身上下 padding 一致；色块、hex 输入、透明度输入对齐间距区 compact 数值输入高度，使用同一高度变量、border-box 并垂直居中；色块按钮不得保留原生 button padding 或使用 scale hover 破坏同高
- 阴影能力行合并选择入口与摘要：token 态在同一个触发器内展示预览和状态名；自定义态不再常驻展示 `自定义` 胶囊，主面板直接展示颜色与参数，来源切换收纳到字段 hover token icon
- 自定义阴影的 `样式` 与 `参数` 必须和文字区一样放在同一个浅灰字段组内，字段行距使用 `6px`，控件横向 / 换行间距使用 `6px`，不要拆成两个独立浅灰块
- 阴影进入自定义时不继承当前 token 值，默认从零值开始：X/Y/模糊/扩散为 `0px`，颜色透明度为 `0`
- 修改记录里如果写入自定义阴影，不能只写 `自定义`，必须同时带上 X/Y/模糊/扩散/颜色等具体值
- 圆角属于外观 token，和背景、边框、阴影一起进入外观模块；命中 token 时展示 token label，自定义时直接展示数值控制，不和间距或布局混放
- 外观 token 区只为真实视觉边界展开；透明背景、无可见边框且圆角为 0 的空外观属于空态，不展示透明 / 无 / 0 的完整控件组，改用 `外观 +` 添加入口
- 间距遵循 token / 自定义双态：命中 token 时展示 token 触发器；进入自定义后不再展示 `自定义` 胶囊，直接在同一能力行内展示内边距 / 外边距四方向；元素间距仅在当前对象本身是 flex / grid 容器且有 2 个及以上可见直接子项时展示，并即时作用到页面，具体数值不在选择器外侧重复展示
- 间距自定义能力行遵守紧凑密度：能力行之间 `4px`，能力行上下 padding `4px`，方向 / gap 输入控件高度约 `28px`，同一能力行内控件间距 `6px`；当元素间距不满足展示条件时，不保留空行或占位

## 最小分类

- 颜色 token
- 排版 token
- 间距 token
- 圆角 token
- 阴影 token

备注：
- 项目早期如果还没定 token，可以先保留分类，不填具体值。
