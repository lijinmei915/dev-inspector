# Token 规范

## 原则

- 颜色、圆角、阴影、字号优先通过 token 管理
- 组件里不要直接散落硬编码视觉值
- 例外值只留在组件自己的语义槽位里
- 控件当前值命中 token 时，触发器和下拉项都必须展示 token label + 原始值；不要只显示裸值
- 未命中 token 的值才按自定义裸值展示
- `自定义` 不是预设项；预设下拉底部只能提供“基于当前样式自定义”动作，进入单项调整后再显示自定义模式
- 紫色只用于 token 命中值和组件语义值；`自定义`、硬编码值、未命中 token 的值一律使用深色文字，不使用紫色强调
- `无`、`0`、`none` 这类空值状态不算 token，使用弱灰或深色文字，不使用紫色
- 阴影遵循 token / 自定义双态：命中 token 时只读展示 token、预览和摘要；进入自定义后才展示 X/Y/模糊/扩散/颜色等参数，并即时作用到页面
- 阴影紧凑栏左侧只作为选择入口，展示状态名；右侧负责展示预览和 token/custom 具体值，避免左右重复展示同一 token
- 阴影进入自定义时不继承当前 token 值，默认从零值开始：X/Y/模糊/扩散为 `0px`，颜色透明度为 `0`
- 修改记录里如果写入自定义阴影，不能只写 `自定义`，必须同时带上 X/Y/模糊/扩散/颜色等具体值
- 间距遵循 token / 自定义双态：命中 token 时只读展示 token 和摘要；进入自定义后才展示内边距 / 外边距四方向或元素间距输入，并即时作用到页面

## 最小分类

- 颜色 token
- 排版 token
- 间距 token
- 圆角 token
- 阴影 token

备注：
- 项目早期如果还没定 token，可以先保留分类，不填具体值。
