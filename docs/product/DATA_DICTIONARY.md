# 数据字典

> 用途：记录当前产品里的业务对象、字段、枚举、状态和对象关系，例如产品、SKU、销货号、客户、订单等。
> 什么时候更新：新增业务对象、字段定义、枚举、状态或对象关系变化时。
> 不要写什么：页面交互细节、业务流程规则、长期路线图、没有数据源的猜测。

## 数据源

优先级从高到低：

1. 已确认的 PRD / 产品说明
2. 当前代码里的类型、接口、schema、数据库表
3. 已上线页面、表单、导入模板、导出样例
4. 用户在当前对话中的明确确认
5. 竞品或行业经验，仅可作为“待确认假设”

没有数据源时，不登记为事实。
