# 业务规则

> 用途：记录当前产品里的编码规则、校验规则、状态流转、导入导出规则和字段约束。
> 什么时候更新：销货号 / SKU / 产品编码规则、字段校验、状态规则或批量处理规则变化时。
> 不要写什么：对象字段解释、页面布局、长期路线图、未经确认的业务假设。

## 数据源

业务规则必须标注来源：

- 用户明确确认
- PRD / 产品说明
- 后端接口或 schema 校验
- 前端表单校验
- 导入模板 / 导出样例
- 线上或 demo 页面行为
