## Inspector 总体原则

- 组件识别成功时，默认展示组件能力和外部布局；不默认展开 DOM 级散样式。
- 普通元素或未识别对象才进入元素样式模块，包括文字、容器、布局、阴影、间距。
- 每个 Inspector 面板只保留一个实底主按钮：底部 `发送给AI`。
- 当前值、选中态、分段控件、tab 和展开入口使用浅底、描边、字色或标记，不使用主按钮视觉。

## 样式面板交互

| 模块 | 默认展示 | 自定义 / 高级 | 规则来源 |
|------|----------|---------------|----------|
| 文字 | 文本内容、文字样式入口 | 字号、字重、颜色单项调整 | `../design/tokens.md` |
| 容器 | 容器预设入口 | 背景、边框、粗细、线型、圆角 | `../design/tokens.md` |
| 外部布局 | 位置 / 尺寸并列紧凑属性表 | X/Y/W/H 数值输入和步进 | `../design/component-index.md` |
| 阴影 | 左侧状态名选择，右侧预览和值说明 | X/Y/模糊/扩散/颜色 | `../design/tokens.md` |
| 间距 | token 摘要行 | 内边距 / 外边距四方向或元素间距输入 | `../design/tokens.md` |

## Token / 自定义规则

- token / 自定义采用双态：命中 token 时只读展示 token 和摘要；进入自定义后才展开参数并即时作用到页面。
- 紫色只表达 token 命中和组件语义命中。
- `自定义`、硬编码值、未命中 token 的值使用深色文字。
- `无`、`0`、`none` 属于空值状态，不算 token。
- 阴影左侧下拉只作为选择入口并展示状态名；右侧负责展示预览和具体值，避免同一 token 重复播报。
- 自定义阴影从零值开始，不继承当前 token；写入修改记录和 AI 任务时必须带具体参数值。

## 组件模式

- 组件卡片默认只展示组件语义名、变体、状态和组件能力。
- 组件内部内容按插槽开放：标题、说明文等可编辑内容只作用当前组件实例。
- 状态标签、图标、按钮等嵌套组件不在父组件里直接改；父组件只提供选择入口。
- 嵌套组件入口按具体类型命名，例如 `标签`；入口内容展示该对象当前的变体 / 状态名，不使用泛称 `子组件`。
- 组件作为页面整体时，可以在组件卡片外调整外部布局。

## 发送给 AI

- `本次修改内容` 是跨对象的本地草稿篮，不跟随当前选中元素清空。
- 标题直接显示本次修改数量，例如 `本次修改内容 3`；不再显示 `已记录 0` 这类空状态徽标。
- 切换选中对象时，已改但未发送的文字、样式、布局等改动必须继续保留在草稿篮里。
- 每个对象记录支持删除图标；删除后需要清除该对象对应的本地草稿，并尽量同步还原页面上的临时效果。
- 每条属性记录支持重置图标；重置后清除该属性的本地草稿，并同步清除对应区块的临时修改。
- 修改记录图标语义：对象级删除使用垃圾桶；属性级移除 / 重置使用减号。
- 输出页面、元素、范围、选择器、改动和定位提示。
- 元素字段使用 Inspector 展示名，真实 selector 单独输出。
- 任务文本应引导 AI 定位源码，而不是手改 `dist`。
