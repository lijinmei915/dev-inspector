# 测试与验收

> 本文件回答：当前项目怎么做最小验证，怎样判断 AI 没有跑偏。
>
> 用途：定义测试方法、最小验收和复测入口。
> 什么时候更新：测试策略、验收标准、复测命令变化时。
> 不要写什么：当前项目状态、交接下一步、与测试无关的路线图。

## 最小检查

- 结构改动后运行：`bash scripts/check-runtime.sh .`
- 路由相关改动后复测对应 case
- 代码改动后记录是否已测、怎么测、还有什么未覆盖

## 路由测试

如果当前项目使用 Project OS 路由，至少确认：

- 项目级请求先进入 `project-setup`
- 设计请求进入 `design-system`
- 页面 / 组件实现进入 `frontend`

## 交付前检查

- `PROJECT.md` 是否反映当前状态
- `HANDOFF.md` 是否写清下一步
- 如果形成新规则，是否更新 `docs/LESSONS.md`
- 如果有结构性变化，是否更新 `docs/CHANGELOG.md`
