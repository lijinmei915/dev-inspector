# Skill Change Log

Every Project OS skill change should record:

```txt
Date:
Skill:
Reason:
Evidence:
Patch:
Validation:
Rollback note:
```

中文说明：
每次改 Project OS 内部 skill，都要记录原因、证据、改动、验证结果和回滚说明。

This folder is for human-approved skill evolution.

AI may propose patches and collect evidence, but humans decide whether to keep them.
